# strongly-typed-vs-weakly-typed

The problem is these definitions are a bit subjective but most of the time we can say following.

- strongly typed language has stricter typing rules at compile time
- weakly typed languages has loose typing rules


# static vs dynamic programming languages

- Static type checking is the process of verifying the type safety of a program based on analysis of a program's text
- Dynamic type checking is the process of verifying the type safety of a program at runtime.
