| Concept                  | C#                | Java              | TypeScript                   |
| ------------------------ | ----------------- | ----------------- | ---------------------------- |
| Integer (32-bit)         | `int`             | `int`             | `number`                     |
| Long Integer (64-bit)    | `long`            | `long`            | `number`                     |
| Floating point           | `float`, `double` | `float`, `double` | `number`                     |
| Decimal (high precision) | `decimal`         | `BigDecimal`      | `bigint` (for integers only) |
| Boolean                  | `bool`            | `boolean`         | `boolean`                    |
| Character                | `char`            | `char`            | `string` (no `char`)         |
| String                   | `string`          | `String`          | `string`                     |
| Null                     | `null`            | `null`            | `null`                       |
| Undefined                | ❌                 | ❌                 | `undefined`                  |
| Void                     | `void`            | `void`            | `void`                       |
